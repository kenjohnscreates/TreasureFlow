Bankr

About Bankr
Bankr provides wallets, token launches, trading tools and payments for onchain apps and agents. Its tools support swaps, bridges, transfers, advanced orders, perpetuals and prediction markets. Agents can also pay for APIs and compute through x402 and Bankr’s LLM gateway.
Build with Bankr Skills, the CLI or the Agent API.

* If you plan to launch a project token, use Bankr to launch, fund and distribute it.

Projects built around onchain equities receive bonus consideration.

Definitive Flash
Definitive Flash
Best Social Trading Build
Build a social trading agent or app using Flash’s advanced order types. You could help people follow another trader, share signals, compare results or trade together.
About Definitive and Definitive Flash
Definitive provides onchain trade execution through its web, mobile and API products. Flash API gives builders access to its execution engine, order routing and managed execution through a REST API and MCP server.
Flash can handle execution while you build the social experience around it:
* Connect an EOA wallet or an embedded wallet such as Privy, Dynamic or Coinbase Embedded Wallets.
* Use the same orders endpoint for advanced order types, with Flash managing execution onchain.
* Attach a fee to trades routed through your integration.
* Connect agents through the MCP server or follow the agent integration documentation.
Track requirements
* Use one or more Flash advanced order types: DCA, Limit, Stop Loss, Take Profit, TWAP or Bracket.
* Either add Flash to an existing product or build a new open-source project specifically for Runtime.
* Submit through Runtime and tag @DefinitiveFi on X with a brief description of what you built.
Ideas to explore
* Copy trading with Flash handling execution.
* Trade signals or leaderboards shared to X, TikTok or other social channels.
* An agent-run trading product that other users can follow.
* Another product that makes trading a shared experience.
Get started
* Get an API key.
* Choose an advanced order type that fits your product.
* Use the agent integration quickstart or MCP setup guide if you are building with an agent.
Prize
$1,000 prize pool. Each winner also receives:
* A dedicated case study featuring their product on Definitive’s channels.
* A dedicated product feature from @DefinitiveFi.

Dynamic
Dynamic
Best Agentic Wallet or Payment Experience
Build an agent that makes or executes a meaningful decision, then pays, transacts or acts for a user through Dynamic.
About Dynamic
Dynamic provides wallet infrastructure for onchain apps and agents. Choose the wallet model for your build:
* Server wallets for automated bots and backend workflows.
* Agent wallets for agents with their own Dynamic user identity.
* Delegated access for agents acting through a user’s wallet with limited, revocable permissions.
Dynamic also supports agent payments through HTTP 402 flows using x402 or MPP.
Track requirements
Use a documented Dynamic wallet pattern and SDK or API to power a working wallet or payment action by the agent.
Ideas to explore
* An agent that pays for an API, retries the request and uses the response.
* A bot that monitors a condition and executes an onchain transaction.
* An assistant that acts for a user within their approved wallet permissions.
* A product where an agent operates its own user-scoped wallet.
